# Markdown & Math Formatting Rules

- **No LaTeX/KaTeX**: Do not output mathematical formulas or dimensions using LaTeX syntax (e.g. `$1 \times 2$`, `$(X, Y)$`, `\times`). Antigravity does not support LaTeX rendering.
- **Use Standard Markdown**: Use inline code backticks (e.g. `1 × 2`, `(X, Y)`), Unicode characters (e.g. `×`, `±`, `²`), and standard plain text for all formulas, dimensions, and coordinates.
